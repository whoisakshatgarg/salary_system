Sync / Exchange

Shared folder

Nothing new to import.

Each machine keeps its own database; this exchanges data as JSON files through the shared folder. The operator exports the month's attendance; the CEO imports it and runs payroll (the CEO's machine is the source of truth). The CEO exports the roster whenever staff change; the operator imports it to stay in sync. Re-importing the same file is safe — it's de-duplicated.

Database backup

This machine holds the master payroll data — back it up regularly. Each backup is a timestamped .zip holding the database and every attached file (mill certificates, employee documents, drawings), saved in data/backups/; "Download a copy" also saves one wherever you choose (e.g. the shared folder).
